# 立绘提示词模板

把下面这段和角色设定一起交给生图模型（火山引擎 Seedream、即梦、其他支持参考图/文生图的模型均可）。

```text
原创国风二次元游戏角色立绘，单人，全身，9:16 竖图。

角色设定：
【名字】
【身份/称号】
【年龄感：青年 / 少女 / 中年，按设定填写】
【性格：温柔 / 爽朗 / 安静 / 狡黠，按设定填写】
【主题色：#______】
【服装与道具：按设定填写，必须为原创设计】

画面要求：
- 中国神话 / 田野 / 丰收 / 谷物 / 灯火等主题；
- 角色站在画面中央，正面或微侧，头部和脚完整，不裁切；
- 全身立姿，一只手做“欢迎/递出”的动作；
- 细腻线稿，柔和厚涂，暖色侧光，高清；
- 纯品红色背景 #FF00FF，纯色、无渐变、无地面、无投影；
- 无文字、无 logo、无水印、无边框、无其他人物；
- 不复刻任何现有游戏、动漫、影视角色的服装、发型、角、纹样或标志性元素；
- 不模仿具体画师签名风格，只使用通用的国风二次元游戏立绘语言。
```

## 生成后的处理

1. 选一张全身完整、表情自然的图；
2. 用抠图工具去掉品红色背景；
3. 检查头发、袖口、手指、脚边是否有品红残留；
4. 导出 **透明背景 PNG**；
5. 建议缩放到高度 1100–1600px；
6. 命名为 `portrait.png`；
7. 与 `pack.json` 一起压成 zip。

## 抠图小技巧

- 品红背景比绿幕更适合绿色系角色，不会把衣服抠掉；
- 如果生图模型没有生成纯色背景，先用“纯色背景 / 去除背景”重绘一次；
- 边缘有品红反光时，用去色/海绵工具轻扫边缘；
- 不要把立绘裁成半身——游戏里的角色会站在柜台旁边，需要全身。

## 不要做

- 不要生成其他游戏/动漫角色的同人立绘并公开分发；
- 不要使用官方立绘、官方截图、官方 logo；
- 不要把多个人物拼在一张图里；
- 不要加文字水印（游戏会自己显示名字）。
