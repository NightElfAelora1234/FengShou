# 穗浪 v6 · 老板娘角色包制作工具

这个文件夹用来让 **玩家自己的 AI** 为《穗浪 v6》制作一个可更换的「老板娘」角色包。

## 游戏里怎么用

1. 进入 **农具小铺**；
2. 点左下角的 **「老板娘 · 穗 / 更换」**；
3. 点 **「导入 .zip 角色包」**，选择制作好的 zip；
4. 选中新老板娘即可立即换立绘、名字和台词；
5. 随时可以切回默认，或删除导入的角色包。

角色包只存在玩家自己的浏览器本地（localStorage），不会上传到任何服务器。

## 压缩包里需要什么

```text
my-boss.zip
├── pack.json        # 角色信息 + 最多 12 句台词
└── portrait.png     # 透明背景立绘（也支持 .jpg / .webp）
```

- `pack.json` 必须是 UTF-8 JSON；
- 立绘建议 720×1100 左右，透明背景，单张不超过 1.8MB；
- **不要**放 `.js`、`.html`、`.exe` 等脚本或可执行文件；
- 游戏只读取图片、JSON，不会执行包内任何代码。

## 让 AI 帮你做

把整个 `boss-pack-kit` 文件夹发给你的 AI，然后发送：

> 阅读这个文件夹里的 `README.md`、`pack.schema.json`、`pack.example.json` 和 `AI_PROMPT.md`。我想做一个老板娘角色包，角色概念是：……

AI 会按 `AI_PROMPT.md` 输出：

1. 完整的 `pack.json`；
2. 一段可直接用于生图模型的 `portrait` 提示词；
3. 需要你手动完成的打包步骤。

AI 不能直接替你生成立绘文件，也不能替你决定版权归属。请只使用：

- 你原创的角色；
- 你拥有授权的角色；
- 明确允许二创/商用的素材。

**不要在公开角色包里使用其他游戏、动漫、影视的角色、立绘或台词。** AI 生成“某某游戏角色”的图仍然是衍生作品。

## 文件说明

- `pack.schema.json`：`pack.json` 的字段规范；
- `pack.example.json`：一个完整示例（示例角色「阿禾」，可替换）；
- `AI_PROMPT.md`：给 AI 的主提示词；
- `IMAGE_PROMPT.md`：给生图模型的立绘提示词模板与抠图要求；
- `CHECKLIST.md`：打包前检查清单；
- `make-pack.ps1`：Windows 下把文件夹压成 zip 的小脚本。
