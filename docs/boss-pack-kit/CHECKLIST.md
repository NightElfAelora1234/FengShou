# 打包前检查清单

- [ ] `pack.json` 是 UTF-8 编码，能被 JSON 解析；
- [ ] `id` 只含小写字母、数字、`-`、`_`，且不是 `sui14`；
- [ ] `name` 已填写，2–24 字；
- [ ] `role` 已填写；
- [ ] `lines` 有 1–12 句，全部原创；
- [ ] 没有复制任何现有作品的台词；
- [ ] `portrait.png` 是透明背景；
- [ ] 立绘是全身，头和脚完整；
- [ ] 立绘高度约 1100–1600px，文件小于 1.8MB；
- [ ] 图片里没有文字、logo、水印；
- [ ] 角色不是其他游戏/动漫角色的复刻；
- [ ] `author`、`license` 已填写或确认；
- [ ] zip 里直接是 `pack.json` 和 `portrait.png`，没有多套一层文件夹；
- [ ] zip 小于 12MB；
- [ ] 没有 `.js`、`.html`、`.exe` 等脚本/可执行文件；
- [ ] 已在游戏里导入，检查立绘和台词显示正常。
